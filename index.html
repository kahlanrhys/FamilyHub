About sync & scanning

Without Firebase connected, data stays only in this browser (localStorage) — nothing leaves the device, but it won't sync to a second phone.

To sync between both of you: create a free Firebase project (console.firebase.google.com), enable Firestore in production mode, paste your config into the Advanced field on first setup, and set this Firestore rule so only people who know your household code can read/write it:

match /households/{code} { allow read, write: if code.size() > 12; } This isn't bank-grade security — it's "not publicly discoverable," matching the no-accounts approach rather than building full logins.

Receipt scanning runs entirely in your browser (no data sent to a server) using an on-device OCR engine, which needs an internet connection the first time it loads. Scanned receipt images are kept on this device only and are not part of the synced data — extracted amount, merchant and text are what sync.
